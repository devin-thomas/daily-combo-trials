# CTR-005 - Content provenance and visual polish

## Goal

Make the challenge feel character-led and lively while keeping every visible string purposeful.

## Scope

- Complete the character/game catalog's descriptions, artwork, trial links, and source credits as available.
- Prefer reviewed official or publisher/developer-hosted art.
- Add responsive visual styling and explicit missing-metadata states.
- Apply the No Useless Copy review method to rendered strings.

## Acceptance Criteria

- Descriptions are paraphrased one-sentence copy with source links where available.
- Images have useful alt text and credit links.
- Unavailable images/descriptions do not create broken or misleading UI.
- Desktop and mobile layouts remain usable without modal navigation.
- No visible internal route names, database fields, placeholder filler, or repeated headings remain.

## Dependencies

CTR-003, CTR-004.
